# 还原保护检测 & 安全关闭工具

> 检测并安全关闭学校/网吧电脑上的硬盘还原保护软件，支持 40+ 种还原保护方案。

## 功能介绍

| 功能 | 说明 | 风险 |
|------|------|------|
| 全面检测 | 扫描进程、服务、注册表、驱动、启动项、计划任务 | 无风险 |
| 安全关闭保护 | 通过软件自身机制关闭保护，提供手动操作指南 | 低风险 |
| 正规卸载 | 查找并执行软件自带的卸载程序 | 无风险 |
| 导出报告 | 生成包含服务和驱动信息的完整报告 | 无风险 |
| 选择性强制关闭 | 用户逐个选择要终止的进程/服务 | 有风险 |

## 使用方法

### 直接运行 exe（推荐）

1. 下载 `还原保护工具v4.exe`
2. 右键 → **以管理员身份运行**
3. 根据菜单提示操作

### 从源码运行

```bash
# 需要 Python 3.8+ 和管理员权限
python disk_protect_killer.py
```

### 自行打包 exe

```bash
pip install pyinstaller
pyinstaller --onefile --console --name "还原保护工具v4" disk_protect_killer.py
```

## 菜单说明

```
[1] 全面检测还原保护软件     ← 先用这个看看检测到了什么
[2] 安全关闭保护（推荐）     ← 通过软件自身机制关闭保护
[3] 正规卸载还原软件         ← 走控制面板卸载流程
[4] 导出检测报告             ← 生成 txt 报告到桌面
[5] 强制关闭（选择性）       ← 慎用！可逐个选择要终止的进程
[0] 退出
```

## 工作原理

### 检测方式

- **进程扫描** — 匹配已知还原保护进程名
- **服务扫描** — 匹配 Windows 服务名
- **注册表扫描** — 检查软件注册表键值
- **文件扫描** — 检查安装目录和驱动文件
- **WMI 驱动** — 通过 WMI 查询系统驱动
- **启动项** — 检查注册表中的开机启动项
- **计划任务** — 匹配计划任务关键词
- **过滤驱动** — 检查磁盘/卷过滤驱动

### 安全关闭策略

| 软件 | 策略 |
|------|------|
| 冰点还原 | 尝试命令行 `bootthawed` 切换到解冻模式 |
| 影子系统 | 尝试 `/exitshadow` 退出影子模式 |
| 鸿合 | 温和停止非核心服务 + 引导通过管理后台操作 |
| 其他 | 温和停止服务 + 查找卸载程序 + 提供手动指南 |

**不会做的事：**
- 不会 `taskkill /F` 强杀保护进程
- 不会重命名/删除正在运行的驱动文件
- 不会直接删除注册表

### 选择性强制关闭

当安全方式无效时，可以使用 `[5]` 功能：
1. 列出所有检测到的进程和服务（带编号）
2. 输入编号选择要关闭的项目（如 `1,3,5`）
3. 需要输入 `FORCE` 确认（防止误操作）
4. 只关闭选中的项目

## 注意事项

- **需要管理员权限** — 右键以管理员身份运行
- **先检测再操作** — 建议先用 `[1]` 检测，了解情况后再决定操作
- **创建还原点** — 操作前程序会提示创建系统还原点
- **强杀有风险** — `[5]` 强制关闭可能导致蓝屏，仅在安全方式无效时使用
- **重启生效** — 大部分操作需要重启电脑才能生效

## 系统要求

- Windows 7 / 8 / 10 / 11
- 管理员权限
- 如从源码运行：Python 3.8+
